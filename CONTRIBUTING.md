# Contributing

[English](CONTRIBUTING.md) | [繁體中文](CONTRIBUTING.zh-TW.md)

Start with an issue describing the workflow, problem, expected outcome, and synthetic example. Discuss cross-module contract changes before implementation.

Submit a focused pull request describing what changes, why, and how it was verified. Update both language versions together; clearly identify unresolved translation differences. Keep technical identifiers identical across translations.

Use only content you are authorized to contribute. Do not submit company code, customer documents, drawings, inspection specifications, personal data, credentials, or real operational records. Build generic examples independently.

For documentation, check relative links and bilingual consistency. For software, include relevant validation of changed behavior, permissions, retries, and quantity reconciliation. No runtime or test commands exist yet.
