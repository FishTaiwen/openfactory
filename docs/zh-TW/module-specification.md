# 模組規格

[English](../en/module-specification.md) | [繁體中文](module-specification.md)

草案 v0.1，以下為待實作規格。

收料模組記錄供應商、料號、採購單參照（可選）、收料明細、供應商批號、數量、單位與收料時間。確認收料後，以同一批次 ID 建立 IQC 任務；草稿不建立任務。

IQC 提供待驗清單，記錄檢驗計畫版次、抽樣依據、量測值、缺點、證據、檢驗員及判定。缺少必要檢驗依據時，不得完成判定。NG 建立品質暫停與處置需求，供應商改善屬後續 NCR／SQE 流程。

| 角色 | 可執行作業 |
|---|---|
| 倉庫 | 確認收料，執行已授權入庫或退貨 |
| 檢驗員 | 記錄證據與權限內的檢驗判定 |
| 品質審查者 | 審查判定疑義，提出處置需求 |
| 指定核准者 | 依設定權責核准特採或處置 |
| 管理員 | 設定權限，不自動取得品質核准權 |

品質狀態草案：PENDING_INSPECTION（待驗）、IN_INSPECTION（檢驗中）、ACCEPTED（允收）、QUALITY_HOLD（品質暫停）、REJECTED（拒收）。CONCESSION_ACCEPTED（特採允收）須有核准紀錄。實際物流狀態另行管理。

MVP 驗收：重複匯入不重複建單；PASS 後倉庫看到可入庫；NG 後禁止放行；未授權核准遭拒；部分處置數量一致；檢驗計畫改版仍保留歷史；判定可匯出而不需重複輸入。
