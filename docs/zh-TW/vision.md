# 願景

[English](../en/vision.md) | [繁體中文](vision.md)

OpenFactory 規劃為開源、可組合的製造管理平台，服務仍依賴 Excel 與人工輸入的團隊。

**資料只輸入一次，之後隨流程流動。** 資料在來源端登錄，收料、檢驗與倉庫作業接續使用。

模組可以選用，介面必須遵循。使用者可採用單一模組，長期再組成更完整的 ERP；財務、成本、稅務與生產管理仍需另行設計。

第一階段 MVP 包含收料、IQC、Excel／CSV 交換及 REST API。成功標準：一筆收料自動建立一筆檢驗任務，品質判定經授權完成後，倉庫直接取得結果，無須重複輸入。

庫存、採購、異常管理、供應商、生產與出貨模組屬後續規劃。
